# Security Policy

## Supported versions

The current `main` branch is supported.

## Data handling

This project is a synthetic portfolio prototype. It must not contain:

- Export-controlled technical data, classified data, ITAR/EAR-controlled details, or real mission identifiers.
- Precise launch, range, orbital, propulsion, payload, telemetry, or recovery details from real programs.
- Supplier names tied to non-public exceptions, safety incident records, or proprietary mission assurance packets.
- Customer data, personnel names, cloud credentials, API tokens, SSH keys, private certificates, or deploy secrets.

## Reporting

Open a GitHub issue for security concerns that do not expose sensitive data. For sensitive issues, contact the repository owner privately.
